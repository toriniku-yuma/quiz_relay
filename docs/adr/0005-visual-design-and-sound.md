# ADR 0005：素朴なフラットデザインと手動割り当ての効果音

日付：2026-09-08。状態：ユーザー要望を反映、実装未検証。

## 背景

ユーザーは、デザインで勝負するゲームではなく、クイズゲームとしての役割に一貫する姿勢を見た目で演出したいと希望した。

## 決定

フラットデザインを基調に、簡潔で余計な装飾のない、一見チープに見えるほど素朴な見た目を採用する。回答ボタンはフラットな表現を維持しつつ、物理的な押しボタンのような凸状とし、段差と押下時の沈み込みで操作を伝える。読みやすさとアクセシビリティは維持する。

効果音をイベントに割り当て可能にする。音源の選定・配置と実際の割り当てはユーザーが手作業で行う。実装では対応設定と編集手順を用意し、初期状態は未割り当てとする。詳細は[仕様書](../specification.md)と[作業方針](../development.md)に集約する。

## 理由と影響

視覚表現をクイズの情報と操作に集中させる。回答ボタンの立体感は押せることを伝えるために用いる。効果音が未設定でも実装・対戦を進められ、ユーザーが後から手動で音を追加・差し替えできるようにする。

## 代替案

装飾を重ねた豪華な画面や写実的なボタンは希望する演出に合わないため採用しない。音源の自動選定・自動割り当てはユーザーが手作業で行う方針に合わないため採用しない。専用の音源管理画面は現時点の要件に含めない。
