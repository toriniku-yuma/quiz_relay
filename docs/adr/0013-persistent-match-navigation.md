# ADR 0013：同じタブでの閲覧と対戦接続の寿命を分ける

日付：2026-09-22。状態：ユーザーと画面方針を合意し、初版実装。

## 背景

通常操作が別タブに分散し、対戦・検証・設定の区別が分かりづらかった。同じタブへ変更するだけでは、ページ移動時に正式対戦の接続が破棄される。

## 決定

共通のサイドバー／スマホメニューを置き、既存の画面パスをHistory APIで切り替える。認証・組織情報を共通化する。正式対戦のコンポーネントは画面移動でも保持し、閲覧先と接続先を区別する。参加処理中・待機中・試合中は他インスタンスの閲覧だけで接続先を差し替えない。復帰バーは参加先を示す。

## 影響と代替案

ページ遷移で毎回再接続する案は、試合中の切断や待機解除を招くため採用しない。訪問した全インスタンスを保持せず、正式対戦の接続は1つに限定する。認証が変われば保持した状態を破棄する。ブラウザーの再読み込みは従来の復帰処理を使う。サーバーの認可・同時参加制限は維持する。
