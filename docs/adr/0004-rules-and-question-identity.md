# ADR 0004：文字ごとの制限時間・7問先取・問題改訂の識別

日付：2026-09-08。状態：ユーザー要望とQ20〜Q24の追加回答を反映。実装未検証。ADR 0002の制限時間と勝敗の決定を更新する。

## 背景

ユーザーから、1文字ごとの持ち時間、7問先取・3回お手つきで失格、問題改訂を新規問題として扱う変更と、将来のマッチング機能が提示された。

## 決定

- 解答制限時間は1文字ごとに数秒。正しい文字から次パネルへ進む際に新しい期限を設定し、同じパネルの再送・再接続では延長しない。初期値の選定は委任されており、1文字3秒を調整用初期値にする。コンフィグの新ルール版で変更可能。
- 先に7問正解した参加者が勝利する。試合累計3回のお手つきで失格となり、以後その試合では解答権を与えない。誤選択と文字の時間切れをお手つきとして数える。
- 10問固定終了と最高得点による同点優勝は現行ルールに適用しない。失格していない参加者が1人以下（全員失格を含む）なら無効。問題枯渇時はその時点の成績で判定する。正解数最多・同数は引き分けという比較基準は仮案で、得点集計とともに未確定。
- 問題改訂では新しいquestionIdを発行する。改訂元を新規出題停止にし、旧問題と過去・開始済み試合の参照を保持し、新問題を採用する問題セットは新しいセット版を発行する。
- Elo系レーティングによる自動マッチング、レートに応じた出題難易度、非レートのルーム戦（準備完了で開始・途中参加可・パスワード付きプライベートマッチ）は将来機能として記録する。

## 理由と影響

文字数によらず各文字を選ぶ時間を持たせる。裁定者は正解数・お手つき数・失格状態と現在文字の期限を永続化し、再送や復帰でも二重加算しない。失格と切断は別の状態として数えるが、失格していない参加者が1人以下の場合も無効試合にする。当該問題のみの誤答ロックは失格者数に含めない。無効条件を通常の勝敗判定より優先する。

問題の識別子を分けることで、改訂後の内容を別問題として出題・参照できる。既存のquestionVersionは固定参照用に保持する案とし、同じquestionIdの増版で改訂しない。過去の問題・結果を上書きしない。改訂元との専用リンクはMVPでは設けず、新規利用停止を不変内容と分けて管理する案。旧セットを選んでも停止済み問題で新しい試合を開始させない。連合先への停止伝達・確認は契約を具体化する。

レーティングの詳細は基本のクイズ機能が完成後に詰める。将来のルーム戦は部屋内の設定で条件を決め、カジュアル戦としてレーティング・ローカルおよび連合ランキングの全指標から除外する。参加条件と結果契約の追加が必要になる。MVPの自動開始・開始後新規参加禁止をルーム戦へ一律適用しない。詳細は[仕様](../specification.md)と[未確定事項](../open-questions.md)を参照する。

## 置き換える案

解答全体で固定の持ち時間を与える案、10問終了時の最高得点で勝者を決める案、同じ問題IDの増版による改訂を今回の指定で置き換える。将来機能の先行実装は行わない。
