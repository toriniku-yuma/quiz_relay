# ADR 0007：責務別の配置とデバッグ画面の分離

日付：2026-09-10。状態：ユーザー指定に基づき採用。

## 背景

従来の計画はclient/workerの大枠だけで、main.tsxに画面と認証・通信を集めていた。ユーザーから改行、将来のファイル蓄積、責務分割、再利用部品の共通化、トップ画面の用途について指摘を受けた。

## 決定

clientをapp・pages・components・features・stylesに、workerをprobes・federationに分割する。mainは起動、indexはルート構成に限定する。TSXは1ファイル1コンポーネントとし、繰り返す部品を共通化する。具体的な依存・追加先はdevelopment.mdに記載。Prettierによる整形をcheckへ組み込む。

/debug/へ検証画面を移動し、トップはquery/hashを維持してリダイレクトする。/design/に色とボタンの比較ページを置く。Authは既存のルートcallbackを維持し、デバッグ画面に到着してから初期化する。

## 影響と代替案

2つの固定ページなのでルーティングライブラリーやUIライブラリーは追加しない。URL選択をapp/へまとめ、正式な画面遷移が増えた際に再評価する。フォルダーは実在する責務に対応させ、将来機能の空ファイルは作らない。検証用DOのexport名・binding・保存キーは維持し、既存保存データの移行を発生させない。

## 未決

最終の配色とボタンは比較後に選ぶ。独立A/Bの参加・正式トップ・ゲーム機能は今回の変更に含めない。

## 2026-09-10：Biomeへの移行

ユーザー指定によりPrettierを撤去し、Biome 2.5.12で整形・推奨Lint・import整理を統一した。具体的な対象とコマンドはdevelopment.mdを参照。
