# 画面の確認：まず1つだけ

**まず「1. 名前の表示」を確認してください。目安は2分です。**

全部で4項目。途中で止めてもOKです。迷った場所が1つ見つかったら、その時点で教えてください。

## 1. 名前の表示を見る（約2分）

[接続確認画面を開く](https://desktop-149oae5.taildd84bf.ts.net:5173/debug/)。必要なら管理者でログインします。

- [ ] 組織名・自分の名前・管理者かどうかが、すぐ分かる。

9月18日の設定では、組織名は「ユーマ鯖」、管理者名は「八葉ユーマ」です。
画面が開かなければ、**「画面が開かない」**と伝えて、ここで止めてください。

## 2. 設定の説明を読む（約2分）

メニューの **組織管理 → 組織設定・アカウント一覧** を開きます。

- [ ] 「インスタンスを追加」の入力例と、「運営担当者の権限設定」の説明が分かる。

今回は読むだけでOK。名前や権限を保存する必要はありません。

## 3. 待機と取消を試す（約3分）

メニュー上部で **競技クイズインスタンス → 対戦する** を選びます。

ダミー問題12問・2人対戦の設定済みです。

表示名を入力して「マッチングする」を押します。履歴画面へ移動して「対戦に戻る」で戻り、最後に「待機を取り消す」を押してください。

- [ ] 別画面から対戦へ戻れて、待機を取り消せる。

1人での待機確認だけでOK。試合を最後まで進める必要はありません。

## 4. 読みやすさを見る（約1分）

今開いている画面を、普段使う端末で見てください。

- [ ] PCのサイドバー／スマホのメニューから、行きたい画面を見つけられる。

キーボードを使う場合は、Tabキーで選択中の場所が見えるかも確認してください。

## 結果は1行でOK

例：**「1はOK。2の識別子が分からない。3と4はまだ」**

「どの画面で・何が分からなかったか」だけで十分です。
