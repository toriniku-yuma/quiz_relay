# 難易度の自動更新

[一覧](../README.md) ／ [作問仕様](../spec/questions.md)

**自己申告から開始し、実力帯ごとの実績で難易度を更新します。** 更新条件の数値と下位帯のデータ不足時の扱いは確定済みです。実装・推定精度の検証は未実施です。

## 使う記録

開催インスタンス・問題の集計世代・実力帯設定版・実力帯・対戦人数・回答ルール版を集計キーにします。帯は試合開始時の開催先レートから固定し、後日のレートや境界変更で過去記録を書き換えません。
出題開始時の回答資格を持つ参加者とレート、問題の正解成立の有無、matchId・出題番号を保存します。集計用actorIdは公開せず、退会時の匿名化・保持方針に従います。
1回の出題を1試行とし、誰かが正解すれば1、無正解で通常終了すれば0です。押し負けた個人を0とするデータには変換しません。INVALIDになる前に完了した問題は含め、途中終了した問題・開発用データ・カジュアル・部屋は除外します。
問題文・表示正答・読み・ひっかけの改訂で新しい集計世代にします。他の項目だけの改訂は世代を引き継ぎます。問題版と集計世代は別に持ち、旧版の記録を消しません。

## 初期方式：実力帯で分けて区間を計算する

レートの全体平均へまとめず、初級・中級・上級の各帯で正解成立率を計算します。対戦人数・回答ルールも混ぜません。自動更新は現在のランク人数・回答ルール・実力帯設定版に一致する集計で判定し、他の集計は運営への参考表示に使います。

試行数を n、正解成立数を k、観測率を p=k/n とします。Wilsonの両側95%区間を以下で計算します。n=0なら未観測とし、0%にしません。

```text
z = 1.959963984540054
D = 1 + z*z/n
C = (p + z*z/(2*n)) / D
H = z * sqrt(p*(1-p)/n + z*z/(4*n*n)) / D
L = max(0, C-H)
U = min(1, C+H)
```

この区間はベルヌーイ試行を独立とみなす近似です。同じ参加者の繰返し・暗記・実力変化・帯内のレート分布の偏りを完全には補正しません。「95%の確率で難易度が正しい」と表示しません。実力帯別の粗い補正であり、連続レートから能力を同時推定するIRTを実装済みとは扱いません。

## 更新する条件

現在の難易度を i とし、対応する実力帯も i とします。区分は易しい順に並べ、実力帯との対応を設定として保持します。

| 判定 | 条件 |
| --- | --- |
| 1段階難しくする | 現在区分に対応する帯で n>=50・異なる参加者20人以上、かつ U<0.50 |
| 1段階易しくする | 1つ下の帯で n>=50・異なる参加者20人以上、かつ L>0.80 |
| 維持する | データ不足、境界内、手動固定、上下の判定が同時成立、対象人数・ルール・実力帯設定が変わり新集計が不足 |

最下位より下・最上位より上には変更しません。条件に使う帯それぞれで最低データ量を満たす必要があります。
50%と80%の間を保留領域にし、同じ程度の成績で難易度を上下させません。両条件が同時成立する場合は参加者構成などの不整合として運営へ確認を促します。
上級者だけの成績から初級者の成績を外挿しません。初めから上級として登録された問題に下位帯の過去記録がなければ、自動では難易度を下げず、運営が判断します。既存の実績がある問題はその帯の証拠を利用できます。
初心者に未確認の難問を試験出題したり、カジュアルの集計を混ぜて不足を埋めたりしません。

## 日次処理と適用

日次処理の論理日付はUTCで固定し、instance・集計世代・日付を一意キーにします。毎分の定期処理が未完了分を回収するため、1回の実行失敗で翌日まで放置しません。再実行で同じ日付の難易度を二重更新しません。
日次処理開始時の集計cursorと設定revisionを固定します。新しい完了出題がない場合は前回結果を維持し、同じデータだけで連日変更しません。1回に1段階まで、同じUTC日に最大1回の変更とします。
保存直前に管理者の固定設定・問題版・設定revisionを比較し、競合した結果は反映しません。難易度変更は有効設定の新revisionとして保存し、次に始まる試合から使います。
運営には自己申告値・現在値・固定の有無・帯別の出題数と成立率・区間・変更理由を表示します。推定値・変更前後・集計cursor・式の版を記録し、判定を再現できるようにします。

## 実装時の検証

式の端点（0/n・n/n）、最低件数未満、20人未満、手動固定、下位帯未観測、上下の矛盾、再実行、改訂・設定変更との競合を確認します。
初級で低成立率なら上がること、上級で高成立率でも初級の実績がなければ下がらないこと、プレイヤー構成・同じ参加者の反復・暗記・期間変化でどれだけ誤分類するかを合成データと隔離した検証で測定します。式の数値確認と、このゲームでの推定性能の確認は別です。
