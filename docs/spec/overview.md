# Quiz Relayの仕様

[ドキュメント一覧](../README.md)

**少しずつ表示される問題を、早押しとひらがなパネルで解く対戦ゲームです。**
名称・素材・画面は独自制作します。仕様の承認と実装完了は別です。[現在地](../README.md)を確認してください。

## 作るもの

| 目的 | 詳細 |
| --- | --- |
| ランク戦で遊ぶ | [ログイン・対戦・レート](gameplay.md)。初期2〜4人、7問先取、3回お手つきで失格 |
| コミュニティを運営する | [組織・運営](organization.md)。1配置1組織、共通アカウントで複数インスタンスを利用 |
| 問題を作る | [作問・審査](questions.md)。本文・許容解答・解説・出典を登録。投稿後の利用・共有は運営が管理 |
| 非レートで遊ぶ | [カジュアル・部屋](rooms.md)。部屋マッチは単体版の完成までに含める |
| 別の運営主体とつながる | [参加・問題・結果の共有](federation.md)。開催元の許可と本人認証が必要 |

管理者は問題・ルールの版、接続先承認・共有設定を管理します。操作時には所有者と権限を確認します。
インスタンス追加のたびに別DB・Auth・デプロイを要求しません。組織間の本人確認と通信は[通信設計](../design/protocol.md)に従います。

連合の例：BのプレイヤーがAで遊ぶと、Aのレートだけが変わります。
共有を許可すればBの本人履歴にも表示します。組織Xのアカウントで組織Yのインスタンスへ参加する機能を含みます。

## 画面と主な操作

基本の画面構成は承認済み。各画面の詳細・URL・未実装機能の完了を意味しません。

| 画面 | できること・表示するもの |
| --- | --- |
| ホーム／マイページ | ランク参加・遊び方・ランキング／表示名変更・本人履歴・振り返り・サイト内通知 |
| 作問／運営 | 自分の問題・申請・資格申請／審査・通報・資格管理・ユーザー処分 |
| インスタンス設定 | 投稿方式・カテゴリ・難易度・表示・モデレーター権限 |
| 部屋一覧・作成・ロビー | 公開部屋への参加、公開／非公開部屋の作成、招待URL・任意パスワード |
| ランク待機 | 開催元・人数・固定ルール・出題方針・取消。成立したら自動開始 |
| 対戦 | 表示済み本文・早押し・解答権・締切・正解数・お手つき・失格・本人の文字パネル |
| 結果／ランキング | 勝敗・レート差分・保存状態・振り返り・再参加／表示名・レート・順位 |

確認する流れは **ホーム → ログイン → 待機 → 対戦 → 結果 → 再参加**。
本人の履歴・作問・通知と、担当権限に合う運営画面にも到達できることを確認します。
他人の個別履歴、未出題問題、審査者名、運営用改訂履歴は一般公開しません。

## メニューと画面移動

PCは常設サイドバー、スマホはハンバーガーメニュー。同じ項目・順序を使います。
通常の移動は同じタブです。History APIで既存パスを切り替えます。

**参加処理中・待機中・対戦中も、他の画面やインスタンスを閲覧できます。**
閲覧先と参加先を分け、正式対戦コンポーネントと接続を保持します。
画面移動だけでは離脱・別試合参加にせず、同時参加制限を維持します。ログアウト時は破棄します。

上部に「対戦中：インスタンス名 ［対戦に戻る］」を固定表示します。
復帰バーは参加先を示し、スマホでもメニューを開かず戻れます。

### 項目の順序

```text
QUIZ RELAY
現在のインスタンス名 ▼
────────────────
対戦する
対戦履歴
ランキング
問題管理
インスタンス設定
────────────────
組織管理 ▸ 組織設定・ユーザー管理
開発ツール ▸ 対戦テスト・接続確認
────────────────
自分の名前
アカウント ▸ ログアウト
```

- 未実装項目は隠す。初版の履歴とランキング、組織設定とアカウント一覧は、それぞれ一体の項目。問題管理・ユーザー管理は実装後に追加する。
- 上部で利用可能なインスタンスを選び、現在の選択とメニュー対象を示す。組織共通とインスタンス別の領域を区切る。
- 問題管理は作問・審査・一覧の入口。必要な権限がある人だけに表示し、サーバーでも認可する。
- 組織管理・開発ツールは管理者だけに常時表示する。一般ユーザーは開発ページの直接URLでも利用不可。検証APIの認可も維持する。

### 操作と見た目

| 対象 | 決定内容 |
| --- | --- |
| スマホの開閉 | 1024px未満は標準dialog。ロゴ横の三本線↔Xで180msスライド。動きを減らす設定では省略 |
| 選択後 | ページ選択は閉じる。インスタンス切替はメニューと候補を開いたまま |
| 現在地 | 白背景・太字。赤線・赤枠を付けない。ロゴ以外の文字は16px |
| アコーディオン | 外枠なし。右の回転矢印・子項目の字下げ。区切った領域に見出し |
| インスタンス切替 | 枠付きセレクト風ボタン。候補は重ねるポップアップ。「インスタンス一覧」は候補の外 |
| アカウント | 上向きポップアップ。名前・メールとメニューの間に余白。下端固定、左右20px、内幅いっぱいの共通Button（枠・下影） |
| サイドバー | PC幅288px、スマホ幅320pxかつ画面幅の90%以内。画面高固定。中央メニューだけスクロール。固定ユーザー欄は白 |
| スクロールバー | 右余白4px、細く低コントラスト。Chromiumは幅6px・上下矢印なし。ホイールを本文へ伝播させない |

初版の幅・余白・見た目は実画面を見ながら調整します。

## デザインと操作性

クイズを主役にした、素朴なフラットデザイン。単色の面・最小限の罫線・文字で構成します。
装飾目的のグラデーション・光沢・背景模様・過剰な影や動きは加えません。
赤白テーマ、Noto Sans JP、段差付きボタンを使います。[判断理由](../design/decisions.md)。

早押し・文字パネルは単色の天面と側面の段差を付け、押すと沈みます。
写実的な質感は不要。押せない状態・フォーカス・正誤を色だけに頼らず示し、タッチとキーボードに対応します。
インスタンス・同期状態は参加条件や結果の信頼性に関わる場所へ、内部ログは管理画面へ置きます。
接続断・再接続中を明示し、RTTを表示します。開催地域の表示は実測可能性を検証し、DOの配置指定を厳密な地域保証にしません。

### 効果音

イベントと音源の対応を1か所で編集する設定と手順を用意します。
基本効果音を同梱し、利用者が音のオン・オフと音量を変更できます。

候補は早押し・文字選択・正解・誤答・開始・終了。文字送り音の要望も記録にあります。

ミュートと無音時の視覚表示を用意し、未設定・読込失敗・再生失敗でも入力や対戦を止めません。

### フロントエンド

React・TypeScript・Tailwind CSS、Viteを使います。繰り返すUIは部品化します。
[実装方針](../development/rules.md)。

## 今回は作らないもの

大会・大会集計・世界共通レートは作りません。
組織間の参加・問題共有・結果共有は作ります。接続先は管理者が登録・承認します。

| 対象外のもの | 意味 |
| --- | --- |
| 未承認の相手との接続（旧「公開連合」） | 知らない運営者を、管理者の承認なしで受け入れる仕組み |
| 接続先の自動発見 | 他組織を自動で探し、接続先へ登録する仕組み |
| ActivityPub互換 | 他のソーシャルサービスとの規格互換。別組織の対戦参加とは別 |

OSSとして公開します。今回の制作では現行のCloudflare Workers・Durable ObjectsとSupabaseの構成を使います。
Cloudflare標準URLと任意の独自ドメインの両方で運用できるようにします。独自ドメインの取得は必須にしません。
Cloudflare非依存化は制作期間を優先して将来タスクとし、今回の完成条件には含めません。Docker Compose等の設置方式は、そのタスクで検討します。
PC・スマートフォンの主要ブラウザーに対応します。
地理的な通信遅延差をなくす厳密な公平性は保証しません。
ランクでは参加者の実力に合わせて出題範囲を制限します。初心者には初級問題だけを出し、上級者には初級問題も出せます。
同じ実力帯で組み合わせ、人数不足でも帯を広げません。実力帯は開催インスタンスのレートから判定し、境界を管理者が設定します。設定人数などの開始条件が揃ったら自動開始します。
カジュアルは実力帯による参加者・出題の制限を設けません。

## 用語

| 言葉 | 意味 |
| --- | --- |
| 組織（オーガナイゼーション） | 管理者・アカウントを共有する配置単位 |
| インスタンス | 問題・権限・レート・マッチング・部屋を管理する単位 |
| 所属元／開催元 | アカウントの所属組織／対戦を進行・採点・確定するインスタンス |
| peer／actor | 管理者が手動承認した相手／originと不変subjectで識別する本人。表示名は識別子ではない |
| competition | コード・DBの対戦条件固定版の識別子。大会機能を意味しない |
| ルーム／match | 接続・裁定の単位／1回の対戦 |
| 確定 | 開催元Postgresに結果とoutboxを保存済み。相手への同期完了とは別 |

UI説明の原稿は `content/*.md`、競技の数値はDB固定版から表示します。[リポジトリの入口](../../README.md)。

## 効果音と対応環境

基本効果音はbuzz・文字選択・本文文字送り・正解・誤答・開始・終了に同梱します。自作または再配布条件を満たす音源だけを使い、出典・ライセンスを同梱します。実装前に素材があることを前提とせず、未配置は検証対象とします。
音源は同一originのMP3を基本に、イベントとの対応を1か所へまとめます。利用者は音のオン・オフと音量を変更でき、文字送り音の過剰な重複再生を抑えます。ブラウザーが再生を拒否した場合も対戦は続け、最初のユーザー操作後に音声を有効化します。
PCはChrome・Edge・Firefox、スマートフォンはiPhone Safari・Android Chromeの現行安定版を検証対象とします。横幅360px以上、タッチ・キーボード操作・動きを減らす設定で確認し、未検証環境を対応確認済みと表示しません。
