# Quiz Relayの仕様

[ドキュメント一覧](../README.md)

**少しずつ表示される問題を、早押しとひらがなパネルで解く対戦ゲームです。**
名称・素材・画面は独自制作します。仕様の承認と実装完了は別です。[現在地](../README.md)を確認してください。

## 作るもの

| 目的 | 詳細 |
| --- | --- |
| ランク戦で遊ぶ | [ログイン・対戦・レート](gameplay.md)。初期2〜4人、7問先取、3回お手つきで失格 |
| コミュニティを運営する | [組織・運営](organization.md)。1配置1組織、共通アカウントで複数インスタンスを利用 |
| 問題を作る | [作問・審査](questions.md)。本文・許容解答・解説・出典を登録。投稿後の利用・共有は運営が管理 |
| 非レートで遊ぶ | [カジュアルマッチ・部屋](rooms.md)。部屋マッチは単体版の完成までに含める |
| 別の運営主体とつながる | [参加・問題・結果の共有](federation.md)。開催元の許可と本人認証が必要 |

管理者は問題・ルールの版、接続先承認・共有設定を管理します。操作時には所有者と権限を確認します。
インスタンス追加のたびに別DB・Auth・デプロイを要求しません。組織間の本人確認と通信は[通信設計](../design/protocol.md)に従います。

連合の例：BのプレイヤーがAで遊ぶと、Aのレートだけが変わります。
共有を許可すればBの本人履歴にも表示します。組織Xのアカウントで組織Yのインスタンスへ参加する機能を含みます。

## 画面と主な操作

基本の画面構成は承認済み。各画面の詳細・URL・未実装機能の完了を意味しません。

| 画面 | できること・表示するもの |
| --- | --- |
| インスタンス一覧／マイページ | 利用できるインスタンスとお気に入り／表示名変更・本人履歴・振り返り・サイト内通知 |
| 作問／運営 | 自分の問題・申請・資格申請／審査・通報・資格管理・ユーザー処分 |
| インスタンス設定 | 投稿方式・カテゴリ・難易度・表示・モデレーター権限 |
| 部屋一覧・作成・ロビー | 公開部屋への参加、公開／非公開部屋の作成、招待URL・任意パスワード |
| ランク待機 | 開催元・人数・固定ルール・出題方針・取消。成立したら自動開始 |
| 対戦 | 表示済み本文・早押し・解答権・締切・正解数・お手つき・失格・本人の文字パネル |
| 結果／ランキング | 勝敗・レート差分・保存状態・振り返り・再参加／表示名・レート・順位 |

確認する流れは **インスタンス一覧 → ログイン → 待機 → 対戦 → 結果 → 再参加**。
本人の履歴・作問・通知と、担当権限に合う運営画面にも到達できることを確認します。
他人の個別履歴、未出題問題、審査者名、運営用改訂履歴は一般公開しません。

## メニューと画面移動

PCは常設サイドバー、スマホはハンバーガーメニュー。同じ項目・順序を使います。
通常の移動は同じタブです。History APIで既存パスを切り替えます。

**参加処理中・待機中・対戦中も、他の画面やインスタンスを閲覧できます。**
閲覧先と参加先を分け、正式対戦コンポーネントと接続を保持します。候補の追加・解除、別インスタンスの閲覧、一覧・管理画面などへの移動では、応答不明の参加処理・自動マッチ待機・部屋ロビー・開始済み試合を取り消しません。遅い参加応答も要求時の接続先へ反映します。待機は対戦中表示・復帰ポップアップの対象外です。
対戦画面の人数・ルール・設定取得エラーは閲覧先に合わせます。終了した試合の詳細・履歴リンクは、その試合のインスタンスを閲覧しているときだけ表示し、元のインスタンスへ戻れば再表示します。
画面移動だけでは別試合参加にしません。新しい対戦・部屋ロビーへの参加が成立すると前の本人だけを強制離脱させ、離脱の確認待ちを含め参加枠を最大2つに制限します。本人の取消・退室、ログアウト、権限・停止状態の変更による制限は維持します。詳細は[カジュアルマッチ・部屋](rooms.md)に従います。ログアウト時は接続を破棄します。
ログアウトまたはセッション切れで非ログイン状態になった場合は、現在の履歴を置き換えて `/game/` のログイン画面へ移動します。起動時の認証切れも対象とし、インスタンス・管理画面の指定は残しません。ログアウト要求が失敗してもローカル認証が解除済みなら移動し、認証を保持している場合は現在の画面で再試行できます。本人の退会手続き情報が保存された退会専用画面では、処理状況の表示を維持します。

上部に「対戦中：インスタンス名 ［対戦に戻る］」を固定表示します。
復帰バーは参加先を示し、スマホでもメニューを開かず戻れます。
同じモードのマッチング画面では、開始済み試合だけに復帰ポップアップを表示します。部屋ロビーも対象外です。閉じても試合を保持し、別のモードを閲覧しただけでは離脱させません。
起動時にログイン情報を取得する間は画面全体に回転アイコンだけのカバーを重ねます。アイコンはテーマ色を半分の濃さで表示します。取得後は透明度をフェードして解除し、フェード中も下の画面を操作できます。動きを減らす設定ではアニメーションを省略します。

### 項目の順序

```text
QUIZ RELAY
組織・インスタンス
  組織名
  インスタンス切替：現在のインスタンス名 ▼
  インスタンス一覧
────────────────
対戦 ▸ ランクマッチ・カジュアルマッチ・部屋・対戦履歴・ランキング
────────────────
作問 ▸ 自分の問題・新規作成・JSON取込・資格申請
──────── 管理 ────────
審査 ▸ 審査待ち・通報・再審議・カテゴリ変更申請
問題管理・共有問題
インスタンス管理 ▸ インスタンス設定・問題共有・結果配送・投稿設定・出題設定
────────────────
組織管理 ▸ 組織設定・ユーザー管理・外部組織との連携
開発ツール ▸ 対戦テスト・接続確認
────────────────
ユーザー
自分の名前
アカウント ▸ マイページ・ログアウト
```

- 未実装項目は隠す。履歴とランキングは別ページとして直接開く。組織設定とユーザー管理は別の項目にし、インスタンス一覧は個別設定への入口にします。
- 上部の切替メニューには本人が明示的に追加したインスタンスだけを表示し、現在の閲覧先とメニュー対象を示す。組織共通とインスタンス別の領域を区切る。
- 作問は閲覧中のインスタンスを利用できる人に表示する。審査は審査権限、問題管理は審査または作者管理の権限、共有問題は審査権限がある人だけに表示し、サーバーでも認可する。インスタンス管理は管理者だけに表示する。
- 組織設定・外部組織との連携・開発ツールは管理者だけに表示する。対戦テストは開発ビルドだけに表示する。ユーザー管理は担当モデレーターにも表示し、操作・閲覧を担当インスタンスに限定します。一般ユーザーは開発ページの直接URLでも利用不可。検証APIの認可も維持する。
- ゲストは対戦のカジュアルマッチ・部屋・対戦履歴と、オプション（ゲスト名を変更・インスタンス一覧）を使う。未ログインでゲストでもない場合は「ログイン」を表示する。

### インスタンス一覧とお気に入り

「インスタンス一覧」は利用可能なインスタンスを探す画面です。各行の「お気に入りに追加」で個別に登録し、追加済みの行には「お気に入り登録済み」と「お気に入りから外す」を表示します。切替メニューはお気に入りの利用可能な先だけを表示し、空なら「お気に入りはまだありません。」と案内します。外部組織のインスタンスも同じ一覧でお気に入りに追加・解除でき、切替メニューに「インスタンス名（組織名）」で表示します。手順は[外部インスタンスのお気に入り](federation.md#外部インスタンスをお気に入りに追加する)に従います。

登録はアカウントごとに保存し、同じ組織・アカウントの別端末でも読み込めます。自組織の公開インスタンス、初回設定・管理者による新規作成、権限付与、直接URLの閲覧・参加による自動追加は行いません。お気に入りから外しても現在の閲覧先や参加は変えません。

未追加の先も、既存の認可に従って直接URLや一覧から通常利用できます。お気に入りへの登録は利用権限・管理者による作成・外部接続先の承認・参加許可と別です。準備中・アーカイブなどで利用できなくなった先は切替メニューから隠し、一覧には解除用の行を残します。名前を取得できない場合は「利用できないインスタンス」と表示し、対戦へのリンクは表示しません。解除しなければ、再び利用可能になったときに本人の登録を使って切替メニューに表示します。管理者の全件管理は本人のお気に入り登録にかかわらず維持します。

各インスタンスの行には、本人が新規参加できる「ランクマッチ」「カジュアルマッチ」「部屋」だけを表示します。公開状態、対戦種別の停止、カジュアルの有効設定、本人の利用制限と対象インスタンスの管理権限を確認します。利用できない種別は表示しません。部屋への参加と部屋作成は別に判定し、作成だけが制限されている場合も「部屋」は表示します。部屋一覧の「部屋を作る」は作成できる本人にだけ表示します。お気に入りの追加・解除は対戦種別の利用可否と独立して操作できます。

表示は取得済みの組織情報に基づき、期限付きの利用制限は期限後に表示へ反映します。参加時にはサーバーが最新の権限・停止状態・出題設定や部屋ごとの条件を再確認します。参加できない種別を隠しても、既存の待機・ロビー・対戦への復帰は妨げません。

## デザインと操作性

クイズを主役にした、素朴なフラットデザイン。単色の面・最小限の罫線・文字で構成します。
装飾目的のグラデーション・光沢・背景模様・過剰な影や動きは加えません。
赤白テーマ、Noto Sans JP、段差付きボタンを使います。[判断理由](../design/decisions.md)。

早押し・文字パネルは単色の天面と側面の段差を付け、押すと沈みます。
写実的な質感は不要。押せない状態・フォーカス・正誤を色だけに頼らず示し、タッチとキーボードに対応します。
インスタンス・同期状態は参加条件や結果の信頼性に関わる場所へ、内部ログは管理画面へ置きます。
接続断・再接続中を明示し、RTTを表示します。開催地域の表示は実測可能性を検証し、DOの配置指定を厳密な地域保証にしません。
読み込みが発生する箇所には、処理中だと分かる回転するアイコンを必ず表示します。

### 効果音

イベントと音源の対応を1か所で編集する設定と手順を用意します。
基本効果音を同梱し、利用者が音のオン・オフと音量を変更できます。

候補は早押し・文字選択・正解・誤答・開始・終了。文字送り音の要望も記録にあります。

ミュートと無音時の視覚表示を用意し、未設定・読込失敗・再生失敗でも入力や対戦を止めません。

### フロントエンド

React・TypeScript・Tailwind CSS、Viteを使います。繰り返すUIは部品化します。
[実装方針](../development/rules.md)。

## 今回は作らないもの

大会・大会集計・世界共通レートは作りません。
組織間の参加・問題共有・結果共有は作ります。接続先は管理者が登録・承認します。

| 対象外のもの | 意味 |
| --- | --- |
| 未承認の相手との接続 | 知らない運営者を、管理者の承認なしで受け入れる仕組み |
| 接続先の自動発見 | 他組織を自動で探し、接続先へ登録する仕組み |
| ActivityPub互換 | 他のソーシャルサービスとの規格互換。別組織の対戦参加とは別 |

OSSとして公開します。現在はCloudflare Workers・Durable Objects・D1とClerkの構成を使います。
Cloudflare標準URLと任意の独自ドメインの両方で運用できるようにします。独自ドメインの取得は必須にしません。
Cloudflare非依存化は制作期間を優先して将来タスクとし、今回の完成条件には含めません。Docker Compose等の設置方式は、そのタスクで検討します。
PC・スマートフォンの主要ブラウザーに対応します。
地理的な通信遅延差をなくす厳密な公平性は保証しません。
ランクでは参加者の実力に合わせて出題範囲を制限します。初心者には初級問題だけを出し、上級者には初級問題も出せます。
同じ実力帯で組み合わせ、人数不足でも帯を広げません。実力帯は開催インスタンスのレートから判定し、境界を管理者が設定します。設定人数などの開始条件が揃ったら自動開始します。
カジュアルマッチは実力帯による参加者・出題の制限を設けません。

## 用語

| 言葉 | 意味 |
| --- | --- |
| 組織（オーガナイゼーション） | 管理者・アカウントを共有する配置単位 |
| インスタンス | 問題・権限・レート・マッチング・部屋を管理する単位 |
| 所属元／開催元 | アカウントの所属組織／対戦を進行・採点・確定するインスタンス |
| peer／actor | 管理者が手動承認した相手／originと不変subjectで識別する本人。表示名は識別子ではない |
| competition | コード・DBの対戦条件固定版の識別子。大会機能を意味しない |
| ルーム／match | 接続・裁定の単位／1回の対戦 |
| 確定 | 開催元D1に結果とoutboxを保存済み。相手への同期完了とは別 |

UI説明の原稿は `content/*.md`、競技の数値はDB固定版から表示します。[リポジトリの入口](../../README.md)。

## 効果音と対応環境

基本効果音はbuzz・文字選択・本文文字送り・正解・誤答・開始・終了に同梱します。自作または再配布条件を満たす音源だけを使い、出典・ライセンスを同梱します。実装前に素材があることを前提とせず、未配置は検証対象とします。
音源は同一originのMP3を基本に、イベントとの対応を1か所へまとめます。利用者は音のオン・オフと音量を変更でき、文字送り音の過剰な重複再生を抑えます。ブラウザーが再生を拒否した場合も対戦は続け、最初のユーザー操作後に音声を有効化します。
PCはChrome・Edge・Firefox、スマートフォンはiPhone Safari・Android Chromeの現行安定版を検証対象とします。横幅360px以上、タッチ・キーボード操作・動きを減らす設定で確認し、未検証環境を対応確認済みと表示しません。
